# Runtime Registry

The runtime registry records execution implementations separately from agent
identity.

| Runtime | State | Purpose |
|---|---|---|
| OpenCode | CURRENT / CTO & TECHNICAL | Established runtime for CTO and technical work |
| Hermes | CURRENT / CEO | Active CEO runtime |

## Runtime Independence

No agent identity is permanently bound to a runtime.

A runtime may be replaced when another approved runtime provides suitable
capabilities.

Runtime changes must not require changing organisational governance or agent
identity.

Runtime-specific hardware, operating-system, model or tool requirements belong
to the runtime/infrastructure layer.

Future runtimes remain candidates until evaluated and approved.

## Hardware Independence

Runtime selection must not assume a permanent hardware platform.

Suitable future runtimes may operate with:

- CPU-only compute;
- NVIDIA accelerators;
- AMD accelerators;
- Intel accelerators;
- other suitable accelerators;
- local compute;
- hybrid compute;
- external compute.

Specific compatibility requirements belong to the relevant runtime or project
record.
