# Mission

To establish a portable, local-first Personal AI Organisation that can
coordinate useful AI work while maintaining owner control over data,
infrastructure, organisational state and decision-making.

## Core Purpose

The organisation exists to:

- coordinate AI-assisted work;
- preserve organisational knowledge and state;
- provide reusable agent capabilities;
- support projects from research through delivery;
- remain independent of any single runtime, model or platform;
- favour local infrastructure where practical;
- use external services selectively when justified.

## Operating Principle

The organisation is the product.

Runtimes, models, tools and infrastructure are replaceable components.

## Success Criteria

The organisation should progressively achieve:

- persistent organisational state;
- clear governance;
- defined and testable agent capabilities;
- project tracking;
- approval and delegation controls;
- auditability;
- runtime and model portability;
- secure local-first operation;
- verified useful outcomes.

Success is measured by reliable capability and useful outcomes, not by the
number of agents or files created.
