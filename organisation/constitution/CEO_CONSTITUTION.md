# Organisation Governance

## Purpose

This document defines the relationship between the organisation-wide
foundation and the authoritative CEO governance document.

## Authority

The authoritative governance document for the CEO is:

`organisation/agents/ceo/CONSTITUTION.md`

This document does not replace or override the CEO Constitution.

The CEO Constitution governs:

- CEO authority;
- CEO responsibilities;
- approval boundaries;
- delegation;
- organisational governance;
- runtime and model independence;
- foundation-building authority;
- agent creation;
- audit and verification.

Organisation-wide documents provide supporting knowledge, policies,
registries and operational definitions.

Where a conflict exists, the CEO Constitution takes precedence for matters
within CEO governance.

Conflicts must be identified and resolved deliberately. Existing information
must not be silently deleted, overwritten, renamed or consolidated merely to
remove a conflict.

## Organisation State Model

Organisational entities should distinguish between:

DEFINED
APPROVED
INSTANTIATED
ACTIVE
SUSPENDED
RETIRED

Definitions describe intended capability.

Approval records authorisation.

Instantiation creates an operational instance.

Active means the instance is currently authorised for operation.

Suspended means the instance exists but is not currently operational.

Retired means the entity is no longer operational but its history is
preserved where appropriate.

## Agent Independence

The following are separate concepts:

AGENT IDENTITY
ROLE / RESPONSIBILITY
AGENT INSTANCE
RUNTIME
MODEL
TOOLS / DATA / KNOWLEDGE
INFRASTRUCTURE

An agent definition does not imply that an agent instance exists.

An agent instance does not imply a dedicated runtime or model.

The organisation must remain portable across approved runtimes and models.

## Current Foundation Status

The organisation is establishing its minimum viable foundation.

The CEO package is established.

The CTO role definition exists as a draft organisational capability
definition.

The CTO is not automatically instantiated merely because its ROLE.md exists.

Research and Creative leadership roles remain proposed capabilities until
there is a demonstrated organisational need and the appropriate approval.

## Foundation Principle

Build the minimum structure required for reliable operation.

Do not create specialist agents, runtimes, models, projects or infrastructure
merely because they appear in a future architecture.

Expansion must be driven by actual organisational requirements.
